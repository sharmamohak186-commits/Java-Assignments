# UCSS553 Unit 1 - Week 3

This folder contains Java-only solutions for both experiments in the assignment.

## Run

From the `ass2 java` directory:

```text
javac -d out src/q1/*.java src/library/model/*.java src/library/service/*.java src/library/utility/*.java src/library/main/Main.java
java -cp out q1.Main
java -cp out library.main.Main
```

The programs use console input and demonstrate inheritance, abstraction, interfaces,
static members, validation, arrays, and package organization.
